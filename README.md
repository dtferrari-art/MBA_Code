Previsão do Consumo de Energia Elétrica no Brasil
Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do MBA em Data Science e Analytics – USP/Esalq.
O estudo avaliou modelos supervisionados para estimar o consumo mensal de energia elétrica no Brasil, considerando diferenças entre sistemas elétricos, classes de consumo, tipo de consumidor, número de consumidores, temperatura média, tendência e sazonalidade.
Objetivo
O objetivo principal foi implementar e comparar modelos preditivos capazes de estimar o consumo mensal de energia elétrica a partir de dados públicos setoriais e climáticos.
O trabalho buscou responder, principalmente, à seguinte questão:
Entre as especificações avaliadas, qual modelo apresentou maior capacidade de generalização para períodos futuros?

Dados utilizados
A base principal foi composta por dados públicos da Empresa de Pesquisa Energética (EPE), complementados por informações climáticas da plataforma NASA POWER.
Período analisado
- Janeiro de 2004 a janeiro de 2026
- 18.168 registros na base original
- 18.086 registros utilizados após os filtros de consistência
